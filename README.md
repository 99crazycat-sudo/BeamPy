# BeamPy

Просмотрщик и физическая симуляция BeamNG-модов на Python.

## Возможности

- 📂 Просмотр дерева файлов `.jbeam`-мода
- 📄 Чтение и структурированный разбор `.jbeam` (ноды, балки, слоты)
- 🖼 Открытие картинок и 3D-моделей (`.png`, `.dae`, `.dts`)
- 🧲 Физическая симуляция разрушения: гравитация, пружины, разрыв балок

## Установка

```bash
git clone https://github.com/99crazycat-sudo/BeamPy.git
cd BeamPy
pip install -r requirements.txt
```

## Данные

Положи папку `lexus_is300` рядом с `main.py`:

```
BeamPy/

├── physics.py

```

## Запуск

```bash
python main.py
```

Меню:

```
1. Просмотр файлов (file_viewer)
2. Физическая симуляция (physics)
0. Выход
```

## Физика

`physics.py` читает `.jbeam`, строит сетку нод и балок и симулирует:

- **Гравитация** — все ноды притягиваются вниз
- **Упругость** — закон Гука для каждой балки
- **Демпфирование** — гасит колебания
- **Разрыв** — если сила > `beamStrength`, балка рвётся
- **Деформация** — если сила > `beamDeform`, балка меняет `rest_length`

Визуализация — VPython в браузере.
